# 🗺️ Tourist Attraction Website

A front-end web application for tourists to search and explore attractions, along with viewing reviews.  
Developed with **React** for a user-friendly interface, fetching data from the server using **Axios**, and styled with **CSS** for a clean and responsive design.

## ✨ Features
- Search for tourist attractions
- View detailed reviews of each location
- Responsive and user-friendly design

## 🛠️ Tech Stack
- **HTML**
- **CSS**
- **JavaScript**
- **React**
- **Axios** (for fetching data)
